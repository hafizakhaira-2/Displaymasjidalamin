# Masjid Display — Islamic Gen Z 🌙

Display masjid aesthetic dengan tema biru, hitam, dan ungu. Dibuat responsif untuk TV, laptop, tablet, dan HP.

### Fitur
- Jadwal shalat
- Countdown menuju shalat berikutnya
- Jam real-time
- Mini tasbih counter
- Doa hari ini
- Pengingat kebaikan
- Dark/light mode
- LocalStorage
- Responsive & fluid

### GitHub Pages
Upload semua file ke repository GitHub, lalu buka **Settings → Pages → Deploy from a branch → main → /root**.

> Catatan: waktu shalat di `app.js` adalah contoh dan sebaiknya disesuaikan dengan jadwal resmi masjid atau lokasi.
